# MN-Doc — محرر مستندات احترافي

تطبيق أندرويد بلغة **Dart / Flutter** لعرض وتحرير المستندات، مع تركيز على:

- 📄 **عرض وتحرير ملفات PDF**: فتح أي ملف PDF، والنقر في أي مكان على الصفحة لإدراج نص جديد (مع اختيار الحجم واللون)، ثم حفظ نسخة معدَّلة من الملف فعليًا.
- 🔍 **Text Erkennung (OCR)**: التقاط صورة بالكاميرا أو اختيارها من المعرض، واستخراج النص منها تلقائيًا عبر Google ML Kit، مع إمكانية تعديل النص المستخرج ونسخه أو حفظه كملف `.txt`.
- 📝 **إنشاء مستندات جديدة**: كتابة عنوان ومحتوى وتصديرهما مباشرة كملف PDF جاهز.
- 📂 **مدير ملفات مبسّط**: فتح أي ملف (PDF / صورة / نص) وعرضه في الشاشة المناسبة تلقائيًا.
- 🎨 هوية بصرية مطابقة لأيقونة التطبيق (كحلي داكن + ماجنتا) مع دعم كامل للعربية (RTL).

### 🤖 ميزات الذكاء الاصطناعي (كلها مجانية)

| الميزة | التقنية | يحتاج إنترنت؟ | يحتاج مفتاح API؟ |
|---|---|---|---|
| **الترجمة** | Google ML Kit Translation (على الجهاز) | لا (بعد أول تحميل لحزمة اللغة) | لا |
| **التعرف الضوئي OCR** | Google ML Kit Text Recognition | لا | لا |
| **التلخيص الاستخراجي** (افتراضي) | خوارزمية محلية في Dart (`LocalSummarizer`) | لا | لا |
| **التلخيص الذكي** (اختياري، أدق) | Gemini API — الفئة المجانية | نعم | نعم (مجاني) |
| **المساعد الذكي للدردشة عن المستند** | Gemini API — الفئة المجانية | نعم | نعم (مجاني) |

**كيفية الحصول على مفتاح Gemini API مجاني (اختياري، لتفعيل التلخيص الذكي والدردشة):**
1. افتح `https://aistudio.google.com/apikey`
2. سجّل الدخول بحساب Google واضغط "Create API key" — لا حاجة لبطاقة ائتمان.
3. الصق المفتاح داخل التطبيق من: الشاشة الرئيسية ← "إعدادات الذكاء الاصطناعي".
4. الفئة المجانية محدودة بعدد طلبات في الدقيقة/اليوم (تكفي للاستخدام الشخصي)، وقد تتغير حدودها من Google مستقبلًا — راجع صفحة أسعار Gemini API الرسمية للتأكد من آخر التفاصيل.

> بدون هذا المفتاح، التطبيق يعمل بكامل ميزاته الأساسية + تلخيص محلي مجاني فوري؛ المفتاح اختياري فقط لرفع جودة التلخيص وتفعيل الدردشة الذكية.

## 🚀 خطوات التشغيل

> يتطلب تثبيت Flutter SDK (3.3 فأعلى) و Android Studio أو أي محرر مع أدوات أندرويد.

1. **إن لم يكن لديك مشروع أندرويد بعد**، أنشئ الهيكل الكامل أولًا ثم انسخ محتوى هذا المجلد فوقه:
   ```bash
   flutter create --org com.mndoc --project-name mn_doc mn_doc_app
   # ثم انسخ lib/ و pubspec.yaml و assets/ إلى داخل mn_doc_app/
   ```
   (هذا ضروري لأن أوامر `flutter create` تولّد مجلدات `android/` و `ios/` الأساسية التي لم يتم تضمينها هنا لتقليل حجم الملفات، حيث تتولد تلقائيًا وتُخصَّص حسب جهازك).

2. **ثبّت الاعتماديات:**
   ```bash
   flutter pub get
   ```

3. **أضف صلاحيات أندرويد**: انسخ محتوى ملف
   `android_manifest_permissions_snippet.xml`
   إلى داخل وسم `<manifest>` في:
   `android/app/src/main/AndroidManifest.xml`

4. **أضف أيقونة التطبيق تلقائيًا** (الصورة موجودة مسبقًا في `assets/icon/icon.png`):
   ```bash
   flutter pub run flutter_launcher_icons
   ```

5. **شغّل التطبيق:**
   ```bash
   flutter run
   ```

6. **لإصدار نسخة نهائية (APK):**
   ```bash
   flutter build apk --release
   ```

## 🧩 ملاحظات تقنية مهمة

- **تحرير PDF**: تم استخدام `syncfusion_flutter_pdfviewer` للعرض و`syncfusion_flutter_pdf` للكتابة الفعلية داخل الملف. مكتبة Syncfusion توفر ترخيصًا مجانيًا (Community License) للأفراد والشركات الصغيرة ضمن شروط معينة — يُنصح بمراجعة الشروط وتفعيل الترخيص المجاني عبر `SyncfusionLicense.registerLicense()` قبل الإصدار النهائي لتفادي العلامة المائية.
- **دقة وضع النصوص**: تم اعتماد وضع عرض "صفحة واحدة" (`PdfPageLayoutMode.single`) داخل المحرر لضمان حساب دقيق لمكان النص المُدرَج عند حفظه داخل ملف PDF الفعلي.
- **OCR**: يعتمد على `google_mlkit_text_recognition` (يعمل محليًا بالكامل على الجهاز، بدون إنترنت، ويدعم اللاتينية بشكل أساسي في هذا الإعداد — يمكن تفعيل سكربتات أخرى مثل العربية عبر تغيير معامل `script`).
- **قابل للتوسعة**: يمكن لاحقًا إضافة دعم لتحرير DOCX مباشرة، وتوقيع PDF، ودمج/تقسيم الملفات، وإخفاء/فرز الصفحات، وبحث نصي داخل PDF (SfPdfViewer يدعم `PdfTextSearchResult` جاهزًا).
